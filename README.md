# Liverary

> Live + library.  
> 수수께끼의 도서관에서 펼쳐지는 모험  
> 카드와 전략으로 스테이지를 정복하고 탈출을 노려라!

---

## 🕹️ 게임 소개
이 게임은 수수께끼의 도서관에서 탈출을 목표로 진행되는 **2D 횡스크롤 + 수집형 RPG + 전략형 카드 배틀 게임**입니다.  
플레이어는 각 스테이지를 탐험하며 카드를 수집하고, 적과 마주치면 **카드 배틀**을 통해 싸우게 됩니다.  

스테이지를 클리어할수록 더 강력한 적과 다양한 전략 선택지가 등장하며, 카드 덱 구성과 전술 판단이 승패를 좌우합니다.
